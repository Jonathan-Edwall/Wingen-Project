Window

Moving windows pool nearby individuals to calculate diversity. Adjacent windows overlap, and an individual can contribute to several windows.

Windows columns summarize eligible raw cell values before kriging. Under latitude or an environmental variable, Window r is the Pearson correlation between those cells and the predictor at each cell. These comparisons are descriptive because the windows overlap.

Location

Nearby sampling sites are grouped by complete-linkage clustering. The grouping distance limits the maximum pairwise distance within a location. Diversity is calculated from pooled genotypes, with rarefaction controlled separately from Window rarefaction.

Each eligible location contributes one equally weighted correlation point. Environmental values are averaged over its member individuals. N sites counts locations with a diversity value; a correlation can use fewer if its predictor is missing.

Neutral comparison

p neutral compares the observed |r| or |ρ| with random neutral SNP sets of matching size, using the same individuals and locations. A small value means the association is unusually strong relative to that neutral genomic background. Sim status “ok” means the comparison is available. Pearson r is a linear correlation; Spearman ρ is a correlation of ranks. The conventional Pearson p, available under “More location statistics”, tests zero correlation.
